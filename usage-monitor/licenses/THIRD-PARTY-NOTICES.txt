Usage Monitor - Third-Party Notices
==================================

This directory records third-party notices for the Windows x64 package.
Original license and notice files are reproduced in licenses/ without edits.
THIRD-PARTY-MANIFEST.json records versions, provenance and SHA-256 digests.
License expressions below describe upstream declarations; the original texts
control the permissions and conditions for each component.

Usage Monitor is an independent wrapper and dashboard. It is not an official
OpenAI product. The upstream codex-usage-desktop accounting/parser sources are
by their upstream contributors, including vincent; Usage Monitor does not
claim authorship of those sources. The upstream MIT notice is preserved in
licenses/upstream/codex-usage-desktop-LICENSE.txt. The pinned source revision
is 6bd0eed7b108497aa50051580387345340e3167f (upstream version 4.2.0).
The source package documents the offline/privacy adapter changes separately.

Bundled runtime and native libraries
-----------------------------------
CPython 3.14.10 Windows x64 embeddable distribution: the complete original
LICENSE.txt, including historical Python licenses, bundled third-party terms,
and Windows binary/Microsoft Distributable Code conditions, is in
licenses/python-3.14.10/LICENSE.txt. This original file is also kept inside
the embedded runtime. The embeddable distribution is extracted byte-for-byte
unchanged into runtime/python, including python314._pth. Usage Monitor's
launcher adds adjacent application scripts and runtime/python-packages to
sys.path at process startup. tzdata is extracted into the separate
runtime/python-packages directory. No CPython source or binary changes.

tzdata 2026.5 (IANA 2026e): original copyright/Apache-2.0 notice and full
Apache-2.0 license are in licenses/tzdata-2026.5/.

Rust Standard Library 1.90.0, x86_64-pc-windows-gnu: the original complete
COPYRIGHT-library.html and accompanying license texts are in licenses/rust/.
They cover the standard library and its own dependencies and retain notices
for targets in the original distribution beyond this Windows package.

GNU runtime: original COPYING.RUNTIME (GCC Runtime Library Exception 3.1),
COPYING3 (GPL version 3), and README.txt from the Rust GNU distribution are
in licenses/gnu-runtime/. The MinGW-w64 runtime notice supplied with the
w64devkit 2.10.1 build tools is preserved alongside these files. The runtime
exception is an additional permission for the runtime code to which it
applies. The compiler and build toolchain are not bundled with Usage Monitor.

SQLite 3.46.0, bundled through libsqlite3-sys 0.30.1: the source's explicit
copyright disclaimer is reproduced verbatim in
licenses/sqlite-3.46.0/SQLITE-COPYRIGHT-DISCLAIMER.txt. The separate Rust
binding and rusqlite MIT licenses are in their cargo component directories.
SQLCipher is not enabled; its notice remains in the original crate notices.

Zstandard 1.5.7, bundled through zstd-sys: BSD-3-Clause notice is in
licenses/cargo/zstd-sys-2.1.2+zstd.1.5.7/zstd/LICENSE. The BSD option is used.
The adjacent zstd/COPYING is the upstream GPLv2 alternative, preserved as
additional original documentation. The Rust zstd wrapper and generated
bindings have their own notices in the zstd, zstd-safe and zstd-sys folders.
